# Desenvolvimento com este kit

Leia [INSTALL.md](INSTALL.md) para instalar ou compilar os exemplos.
A API pública está em `include/`; as bibliotecas prontas estão em `lib/`.
Use `make check` para validar o SDK e `make clean` para limpar demonstrações.
As fontes de implementação são mantidas pelo fornecedor. Para distribuição e uso, consulte `LICENSE`.
